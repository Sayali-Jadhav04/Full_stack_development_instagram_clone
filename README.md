# Full_stack_development_instagram_clone
Instagram Clone is a full-stack web application inspired by Instagram. It allows users to create accounts, log in, share posts, view profiles, and interact with content.
The project was built to learn and implement both frontend and backend web development concepts.

Features
1. User Registration and Login
2. User Authentication
3. Create and Upload Posts
4. View User Profiles
5. Responsive User Interface
6. Dynamic Content Rendering
7. Secure Backend with Django

Technologies Used
Frontend:- HTML,CSS,JavaScript
Backend:- Django,Python
